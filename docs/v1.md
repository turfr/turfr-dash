Turfr Dash v1.0

Purpose
Community-facing visibility into Turfr's bookkeeping.

Source
Read-only published representation of the community Google Sheet.

Flow
Source → Adapter → DashboardData → UI

v1.0 shows
- Current fund
- Match collection
- Sponsors
- Purchases
- Donations
- Activity
- Community / Discussions entry point

v1.0 does not
- mutate the source
- write back to the Sheet
- own bookkeeping
- authenticate users
- manage players
- manage matches
- process payments
- replace the Sheet

Design principle
The source records facts.
Dash transforms and presents them.
Derived dashboard values are calculated by Dash.
